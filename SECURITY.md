# Security Policy

## Reporting a Vulnerability

Security is paramount at EnvCrypt. If you discover a security vulnerability within EnvCrypt CLI, please do **NOT** open a public issue.

Instead, please send an e-mail directly to **vijayvenkatj@gmail.com**. We will treat your report with the highest priority and will work with you to resolve the issue responsibly.

### What to include
- A description of the vulnerability.
- Steps to reproduce it.
- Possible impact.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.
